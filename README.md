# Apuntes DAW
Material del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web**: Bases de Datos, Desarrollo Web en Entorno Servidor y Big Data e Inteligencia Artificial. Teoría, ejemplos y actividades organizados por unidades, que se van publicando a lo largo del curso.

Los apuntes se leen mejor en la web, con su buscador y su navegación:

Y con ellos, todo lo necesario para trabajarlos: datasets, scripts y ficheros de cada unidad, ordenados por módulo.

# «For Noobs»: desde cero
Para empezar un lenguaje sin saber nada y llegar a escribir código propio, paso a paso.

**JavaScript for Noobs.** Los fundamentos del lenguaje en ficheros numerados, uno por concepto: variables, operaciones, tipos de datos, estructuras de control, funciones, scope y spread operator.

[![JavaScript for Noobs](https://img.shields.io/github/stars/codigoRonin/javaScript-for-noobs?label=Repositorio%20-%20JavaScript%20for%20noobs&style=social)](https://github.com/codigoRonin/javaScript-for-noobs)

**Kotlin for Noobs.** Primeros pasos con Kotlin.

[![Kotlin for Noobs](https://img.shields.io/github/stars/codigoRonin/kotlin-for-noobs?label=Repositorio%20-%20Kotlin%20for%20noobs&style=social)](https://github.com/codigoRonin/kotlin-for-noobs)

**Jetpack Compose for Noobs.** Interfaces Android con Jetpack Compose, con un repositorio aparte de ejercicios para practicar.

[![Jetpack Compose for Noobs](https://img.shields.io/github/stars/codigoRonin/jetpack-compose-for-noobs?label=Repositorio%20-%20Jetpack%20Compose%20for%20noobs&style=social)](https://github.com/codigoRonin/jetpack-compose-for-noobs)
